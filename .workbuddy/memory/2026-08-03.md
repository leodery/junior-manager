## 微信 X5 内核适配（8月3日 23:00+）
- 用户反馈：在微信里打开后页面只占左半边（右侧大片空白）+ 没有 App 图标
- 根因：QQ/微信 X5 内核默认以 PC 模式渲染（viewport 980px），移动端断点 820px 不触发 → 桌面 grid 布局挤在左侧
- 修复 1：head 加 3 个 X5 专用 meta（x5-page-mode=app / x5-orientation=portrait / x5-fullscreen=true）
- 修复 2：响应式断点 820→1024、560→720（让 980px X5 视口也走移动布局）
- 修复 3：加浏览器提示 banner，UA 检测到 Micromessenger/QQBrowser/MQQBrowser 时顶部黄色提示"用手机浏览器打开"
- 教训：**PWA 在微信内置浏览器里**永远无法添加到主屏幕**（微信策略限制），必须引导用户用 Safari/Chrome → 分享 → 添加到主屏幕
