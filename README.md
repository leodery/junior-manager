# 🌟 我的初中全能管家 — AI-Powered Junior High School Workbench

> **全栈 PWA 应用** | 移动端优先 | 马卡龙色系 iOS 风格 | 离线可用 | AI 驱动

## 🏆 项目概述

「我的初中全能管家」是一款面向初中生的 AI 智能学习工作台，将**日程管理、任务看板、刷题练习、错题分析、复盘笔记**五大核心场景整合为一个 PWA 应用。创新性地融合了 **AI 视觉识别（OCR）、自动知识分类、同类题生成引擎、双层 AI 讲解系统**，实现从"拍题→分类→练习→讲解→复盘"的全流程智能化。

## 🤖 AI 创新功能详解

### 1. 拍照 OCR 识别
```
拍照 → Gemini Vision 多模态识别 → 自动提取：科目、知识点、题目、选项、答案、解析
```

### 2. 自动知识分类引擎
- **本地层**：初中全科知识库（9科 × 50+知识点 × 300+关键词），加权匹配算法
- **云端层**：Gemini 2.0 Flash 精准分类
- **智能粘贴**：粘贴大段文字自动触发分类

### 3. 同类题生成引擎
| 学科 | 变异策略 |
|------|---------|
| 数学 | 数字缩放替换（0.5x-2x）+ 人名随机替换 |
| 英语 | 时态/时间状语替换 + 干扰项重组 |
| 通用 | Fisher-Yates 选项洗牌 + 语义标注 |

### 4. 双层 AI 讲解
- **离线层**：按学科定制的 4 步解题框架 + 选项逐一分析 + 易错提醒
- **在线层**：Gemini 2.0 Flash 实时深度讲解，缓存复用
