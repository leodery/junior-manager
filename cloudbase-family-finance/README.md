# 家庭理财工作台 · 多手机共享版（CloudBase 改造版）

> 原版使用 Supabase，因国内网络 + 邮箱验证不友好，已改造为**腾讯云开发 CloudBase**。
> 家人打开同一个地址就能看到你刚加的收入/支出，手机秒同步，无需注册邮箱。

---

## 🚀 5 分钟让全家手机都用上

### 第 1 步：开通腾讯云 CloudBase（免费）

1. 浏览器打开 <https://console.cloud.tencent.com/tcb>
2. 用你的微信 / QQ 登录
3. 点击「**新建环境**」
   - 名称：随便填，比如 `family-finance`
   - 套餐：选「**包年包月** → 基础版 0 元」（新用户有 1 个月免费额度，够家用）
4. 创建后点进环境，**复制「环境 ID」**（形如 `family-finance-1xxxxxxxxxx`）
5. 进入环境 → 左侧「**安全配置**」→ 「**Web 域名白名单**」 → 添加 `localhost` 和你之后要部署的域名（先用 `localhost` 即可）
6. 进入「**数据库**」→ 确认开通（默认就开）→ 创建 3 个集合：
   - `families`
   - `family_members`
   - `family_snapshots`
7. 进入「**安全配置**」→ 「**登录授权**」 → 开启「**匿名登录**」

### 第 2 步：把环境 ID 填进 HTML

打开 `家庭理财工作台.html`，找到文件最上方的：

```js
const CLOUDBASE_ENV = 'family-finance-demo';   // ←← 改成你的环境 ID
```

把 `'family-finance-demo'` 替换成你刚才复制的真实环境 ID。**只改这一行**。

### 第 3 步：本地试一下

直接双击 `家庭理财工作台.html` 打开 → 选「**创建家庭（我是管理员）**」→ 填称呼（如"爸爸"）→ 填家庭名（如"李家账本"）→ 提交。

成功后：
- 顶部状态栏会出现「**📋 复制邀请码**」按钮
- 右侧分享面板会显示一个 6 位邀请码（如 `A2K9P3`）

### 第 4 步：把邀请码发给家人

微信发个消息：

> 「打开这个链接，用邀请码 **A2K9P3** 加入我们家账本」
> 链接 = 你电脑当前打开的页面 URL（如果还没部署，就先用本地 IP 的方式，见下）

家人在手机浏览器打开链接 → 选「**加入家庭**」→ 填自己的称呼（如"妈妈"）→ 填邀请码 → 提交。

**之后你在电脑加一笔支出，家人手机上 1-2 秒内就能看到。** 一人改，全家同步。

## 📱 让家人用 URL 打开（4 种方式）

| 方式 | 操作 | 适用 |
|---|---|---|
| **A. 部署到 CloudBase 静态托管**（推荐） | 右侧栏「静态托管」→ 上传 `家庭理财工作台.html` → 拿到一个永久 https URL | 长期使用，所有家人都能直接打开 |
| **B. 微信传文件** | 把 HTML 文件微信发给家人 → 家人用浏览器打开 | 临时测试 |
| **C. 电脑起服务** | 电脑执行 `启动本地服务.bat`，手机连同 Wi-Fi 访问电脑 IP | 不想注册云、只在 Wi-Fi 下用 |
| **D. 内网穿透** | 用 cpolar / frp 等把电脑端口暴露到公网 | 折腾党 |

### 方式 A · 上传到 CloudBase 静态托管

1. CloudBase 控制台 → 进入环境 → 左侧「**静态网站托管**」
2. 点击「**上传文件**」→ 上传 `家庭理财工作台.html`
3. 上传后点文件名 → 「**基础配置**」→ 设为默认首页
4. 顶部会显示访问域名：`https://family-finance-1xxxxxxxxxx.tcloudbaseapp.com`
5. 把这个域名：
   - 填回 HTML 第 2 步的 `CLOUDBASE_ENV` 旁边（如果你要做成"扫码直达"二维码，部署完直接用这个 URL 即可）
   - 加进 CloudBase 控制台「Web 域名白名单」
6. 微信把这个 URL 发给家人，扫码 / 点击就能用

### 方式 C · 本地服务（无需云）

双击运行 `启动本地服务.bat`，会显示：

```
========================================
  家庭理财手机共享已启动
  电脑访问：http://localhost:8000
  手机访问：http://192.168.3.34:8000
========================================
```

把 `192.168.3.34` 改成你电脑实际 IP（脚本会自动获取），让手机连同一个 Wi-Fi 打开即可。
**注意**：换 Wi-Fi 或电脑关机后，URL 就失效了，要重新部署到云才能长期用。

## 👨‍👩‍👧‍👦 权限说明

| 角色 | 谁该用 | 能做什么 |
|---|---|---|
| **管理员 (admin)** | 创建家庭的人（爸爸/妈妈） | 全部 + 删除记录 + 重置邀请码 + 踢人 |
| **成员 (editor)** | 配偶、孩子（10 岁以上） | 录收入 / 支出 / 目标，生成月度报告 |
| **只读 (viewer)** | 小孩子 / 父母长辈 | 仅查看，不误改 |

- 第一个创建的人是**管理员**
- 后续通过邀请码加入的人默认是**成员**
- 管理员可以在 CloudBase 控制台 `family_members` 集合里改某人的 `role` 字段，刷新后生效

## ❓ 常见问题

**Q: 我家人点开链接后看不到我加的记录？**
A: 三步检查：
1. CloudBase 控制台 → `family_snapshots` 集合里有没有数据
2. Web 域名白名单有没有加上这个域名
3. 家人是不是用了同一个 6 位邀请码

**Q: 一个手机能同时用两个家庭吗？**
A: 当前版本不行。一个浏览器一个家庭。如果要切换家庭，点"退出家庭"再用新邀请码。

**Q: 我想踢掉某个人？**
A: CloudBase 控制台 → `family_members` → 找到那个人 → 删除该条记录。

**Q: 数据会不会丢？**
A: 数据存在 CloudBase 数据库（腾讯云机房），比家里电脑硬盘稳。每月记得「导出家庭账本」做本地备份（管理面板里有这个按钮）。

**Q: 我现在是"本地演示模式"怎么办？**
A: 说明你还没填环境 ID。按上面第 2 步把 `CLOUDBASE_ENV` 改成你的真实环境 ID 即可。之前的本地数据会被保留（按月存在 localStorage），重新加入后会自动恢复。
